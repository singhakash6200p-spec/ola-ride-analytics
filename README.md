## 📌 Project Overview
An end-to-end data analytics project analyzing **103,024+ Ola ride records** using SQL, Python, and Streamlit. This dashboard provides insights into booking patterns, cancellation reasons, vehicle performance, and pickup location trends.

## 🛠️ Tech Stack
- **Database:** SQLite (SQL)
- **Language:** Python 3.9
- **Libraries:** Pandas, Plotly
- **Dashboard:** Streamlit
- **Version Control:** Git & GitHub

## 📊 Key Insights
| Metric | Value |
|:---|:---|
| Total Bookings | 103,024 |
| Cancellations | 28,933 |
| Cancel Rate | 28.1% |
| Avg Wait Time (V_TAT) | 171 seconds |

**Top Findings:**
- Cancellation rate is significantly high at **28.1%**, mostly driven by customer-side cancellations.
- **Cox Town, Tumkur Road, and Vijayanagar** are the top 3 pickup locations.
- **Auto and Prime Sedan** are the most booked vehicle types.
